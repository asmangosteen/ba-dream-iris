# 10. 오류 · 저장 위험 알림

> Iris 에서 생길 수 있는 오류의 경우의 수와, 각각을 **어떤 모양(토스트 · 알림 막대 · 창 · 화면)으로 어떻게 알리는지** 정리한 기준표입니다.
> 기준은 피그마(웹 · 데스크톱)입니다. 네트워크 문제와 **저장이 안 될 위험**을 가장 먼저 다룹니다. 2026-11-25 첫 전수 점검.
> 새 기능을 만들 때 실패할 수 있는 곳이 생기면 이 표에 한 줄 더하고, 아래 모양 규칙대로 알립니다.

## 1. 피그마는 어떻게 하나(조사 결과)

직접 확인한 것: 테스트용 피그마 파일에서 연결을 끊고 사각형을 그려 봄 + 도움말 · 커뮤니티 조사.

| 상황 | 피그마 동작 | 확인 |
|---|---|---|
| 연결이 끊김 | 왼쪽 아래에 **구름 ×** 아이콘. 올리면 "Offline changes will be synced with Figma when you go online." | 직접 |
| 끊긴 채 수정 | 도구 막대 위에 **닫을 수 있는 검은 알림**: "This file has unsaved changes. Learn more". 변경은 브라우저(IndexedDB)에 보관 | 직접 |
| 끊긴 채 탭 · 창 닫기 | 브라우저의 "사이트에서 나가시겠습니까?" 확인 창(문구는 피그마가 못 바꿈). 데스크톱 앱은 '버리기 / 나가기' 선택 창 | 직접 + [도움말](https://help.figma.com/hc/en-us/articles/360040328553) |
| 다시 연결 | 조용히 저장하고 구름 아이콘이 사라짐(따로 토스트 없음) | 직접 |
| 보관한 변경이 남은 채 다시 열기 | 파일 목록 아래 파란 알림 "Tap to review" → 변경이 남은 파일 목록 → 열어서 저장. 저장되면 확인 알림. 크롬 30일 · 사파리 7일 보관 | [도움말](https://help.figma.com/hc/en-us/articles/360040328553) |
| 다른 사람 수정과 겹침 | "겹치는 변경이 있어요" 알림 → Review(버전 기록) / Dismiss | [도움말](https://help.figma.com/hc/en-us/articles/360040328553) |
| 보관 못 하는 경우 | 시크릿 창 · 브라우저 데이터 삭제 · 저장 공간 가득 · 다른 브라우저 | [도움말](https://help.figma.com/hc/en-us/articles/360040328553) |
| 서버 연결 오류 | 창: "Your computer may be offline or the Figma server may be experiencing problems. Figma will automatically try to reconnect." + Try again | [커뮤니티](https://forum.figma.com/report-a-problem-6/connection-error-109-50131) |
| 권한이 사라짐 | 빨간 알림 "You don't have access to this file" / "Someone revoked your access" 후 파일 닫힘 | [커뮤니티](https://forum.figma.com/archive-21/fixed-you-don-t-have-access-to-this-file-24419) |
| 메모리 한도 | 60 · 75 · 100% 에서 알림, 100% 면 잠금 · 복구 모드 | [도움말](https://help.figma.com/hc/en-us/articles/360040528973) |
| 큰 이미지 | 4096px 넘으면 줄여서 넣음, 클립보드에 너무 크면 "Copy failed" | [커뮤니티](https://forum.figma.com/t/maximum-image-size/3203) |

뺀 것(필요 없음): 메모리 한도(Iris 는 DOM 캔버스 · 파일 크기 작음), 플러그인 · 라이브러리 · AI(Make) 오류, 결제 · 조직 잠금, 버전 기록 충돌 검토(Iris 에 버전 기록 없음).

## 2. 알리는 모양 규칙

| 모양 | 언제 | 생김새 |
|---|---|---|
| **토스트** | 한 번 일어나고 끝난 일(실패 · 성공). 3초(실패는 4초) 뒤 저절로 사라짐 | 도구 막대 위 검은 알약. 끊긴 상태에서 실패하면 뒤에 "· 인터넷 연결이 끊겼어요"를 붙임 |
| **알림 막대** | 계속되는 위험(끊김 · 저장 실패). 상태가 풀릴 때까지 남음, × 로 닫으면 상태가 바뀔 때까지 숨김 | 토스트와 같은 검은 면 + 노란 경고 아이콘 + 동작 버튼(파랑) + × |
| **머리줄 표시** | 지금 상태를 늘 보여 줌 | 왼쪽 패널 파일 이름 옆: `오프라인`(경고 아이콘) · `저장하는 중…` · `저장하지 못했어요 · 다시 시도`(빨강) |
| **창(확인)** | 사용자가 골라야 할 때(복구 · 다시 로그인 · 페이지 지우기) | 공용 `components/app/AppConfirm.vue` — 기존 팝업(프로필 편집 창)과 같은 양식: 바탕 dimmed · 폭 360 · 모서리 radius-08 squircle · 흰 면 · 그림자 0 12 20 · 머리 48(제목 14/600, ×) · 안쪽 16 · 디자인 시스템 Button s(tertiary · primary · destructed) |
| **화면** | 화면 자체를 못 그릴 때(불러오기 실패) | 캔버스 자리 가운데 아이콘 · 제목 · 설명 · 버튼 |

## 4. 동작 원리(개발 메모)

- 자동저장: 화면마다 0.6초 모아 저장(`canvas/store.ts`). 실패하면 그 화면 내용을 `localStorage` 의 `iris-unsaved:<프로젝트>` 에 보관(`composables/useUnsavedBackup.ts`)하고 2 · 5 · 10 · 30초 간격으로 다시 시도. 성공하면 보관본을 지움.
- 연결: 브라우저 `online` · `offline` 이벤트. 다시 연결되면 바로 남은 저장을 함.
- 편집기를 떠날 때(탭 닫기 · 다른 화면 · ⌘R): 남은 저장을 최대 2.5초 기다리고, 그래도 못 하면 보관본으로 다음에 복구. 보관도 못 했을 때만 묻고 나감. 떠난 편집기는 더 다시 시도하지 않음(새로 연 편집기의 복구본을 옛 내용이 덮어쓰지 않게).
- 미리보기 모드(개발용)도 브라우저가 오프라인이면 저장 · 불러오기가 실패하게 해서 이 화면들을 확인할 수 있음.
- 보관은 이 브라우저에만 남음: 시크릿 창 · 브라우저 데이터 삭제 · 다른 기기에서는 복구할 수 없음(피그마와 같음).
