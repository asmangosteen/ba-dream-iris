# Iris(이리스) — 디자인 문서

> Show Me The PRD로 생성됨 (2026-11-22)

화면을 클릭하면 그 화면에 반영된 **기획 요구사항 · 관련 문서 · 사용 컴포넌트**가 바로 보이는, 바드림 전용 웹 디자인 협업 툴입니다. 피그마 연결 허브로 시작해 캔버스 기능을 하나씩 붙여 점진적으로 피그마를 대체합니다.

## 이름의 뜻

**Iris(이리스)** — 그리스 신화에서 무지개의 여신이자, 신들과 인간 사이를 오가며 소식을 전한 전령입니다.
- **무지개(색)** → 디자인 툴
- **전령(연결)** → 기획의 요구사항을 화면에, 화면의 정보를 개발에 전하는 툴
- 토스 'Deus'(라틴어로 '신')처럼 신화에서 이름을 가져왔습니다.

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 사용자 | 바드림 사내 크로스팀 5~20명 |
| 피그마와의 관계 | 지금은 연결(허브) → 캔버스 기능을 단계적으로 추가 |
| 제작 | 기획자 1인 바이브코딩, Phase 1 = 1주 |
| MVP | 프로젝트 허브 + 피그마 연결 + 기본 캔버스 + 컴포넌트·토큰 목록 |
| 문서 | 툴 안 작성 + 외부 링크 읽기 + 파일 업로드 → 하나의 읽기 뷰 |
| 요구사항 추출 | Phase 1 번호 규칙 자동 + 직접 지정 → Phase 2 AI 초안 |
| 기술 | Nuxt 4(Vue) + 바드림 디자인 시스템 + Supabase + 자체 DOM 캔버스(Deus 방식) + Vercel |
| 로그인 | `@ba-dream.com` 이메일 인증코드 |
| 디자인 | `@ba-dream/design-system`(Vue 3) + AUTO-MAKE 규칙, 무드는 design-system.ba-dream.com |
| 이름 | Iris(이리스): 기획·디자인·개발을 잇는 무지개 |

## 레퍼런스 요약

- **토스 Deus** ([Simplicity 세션](https://toss.im/simplicity/sessions/the-last-design-tool), [토스테크 모닥불 EP.11](https://toss.tech/article/firesidechat_frontend_11))
  - 구조: DOM·웹 컴포넌트 기반이고, Core / Application / Extension(플러그인) 3층으로 나뉜다. `Project → Page → Frame` 트리를 쓴다.
  - UI: 컴포넌트 props로 속성 패널을 자동 생성한다. 레이어 트리에서 컴포넌트 인스턴스를 색으로 구분한다.
  - 생김새: 흰색 플로팅 패널, 알약 모양 툴바, 시맨틱 토큰을 고르는 속성 패널.
  - 협업·핸드오프: 코드 탭(React/iOS/Android), 스냅샷 고정·복구.
- **디테일페이지스튜디오** ([사이트](https://detailpagestudio.com/#/home))
  - 목적별 시작 카드
  - 입력 → 기획 → 제작 → 검토 흐름
  - 섹션을 "내 모듈"로 승격
  - 연속·펼침·슬라이드 다중 보기
  - AI 요청 내역 패널
- **기타**
  - [Penpot](https://penpot.app), [OpenPencil](https://github.com/open-pencil/open-pencil): 오픈소스 피그마 대안. 구조 참고용.
  - [tldraw](https://tldraw.dev/pricing): 사내 운영 시 유료 라이선스가 필요해서 제외했다.
