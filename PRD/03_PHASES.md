> 한 번에 다 만들면 복잡해져서 품질이 떨어집니다.

## Phase 1: MVP — "화면을 누르면 기획이 보이는 허브" + 기본 캔버스 (1주, 2026-11-23 ~ 11-29)

### 목표
팀원이 회사 이메일로 로그인한다. 실제 바드림 프로젝트의 문서와 화면(피그마 연결 또는 직접 제작)을 등록하고, **화면을 클릭해 반영된 요구사항과 사용 컴포넌트를 확인**한다.

### 기능
- [x] `@ba-dream.com` 이메일 인증코드 로그인, 멤버 프로필(이름·직무)
- [x] 프로젝트 홈: 카드 목록, 반영률, 새 프로젝트(시작 카드: 앱/웹/상세페이지)
- [x] 에디터 셸: 좌측 패널(Pages/Layers/Assets/Docs), 중앙 캔버스, 우측 패널(디자인/기획/개발), pill 툴바
- [x] 페이지 캔버스: 무한 캔버스 줌(휠·핀치·단축키)·이동(스페이스+드래그), 화면 배치·이동, 화면 이름 라벨
- [x] 피그마 화면 연결: 링크 → 썸네일·레이어 요약 저장, 수동 '다시 불러오기'
- [x] 자체 캔버스 기본 편집
  - 그리기: 프레임·사각형·텍스트·이미지(업로드)
  - 편집: 선택·다중선택·이동·크기조절, 레이어 트리(이름 변경·순서·숨김·잠금)
  - 속성 패널: X/Y/W/H, Fill, Stroke, Radius, Opacity, 텍스트 스타일
  - 실행취소/다시실행, 복사/붙여넣기/삭제, 자동저장
- [x] 문서 3종 + 읽기 뷰: 블록 에디터 작성 / PDF·DOCX·MD 업로드 / 외부 링크 본문 가져오기 (실패 시 링크 카드 + "본문 붙여넣기")
- [x] 요구사항: 번호 규칙 자동 인식 + 텍스트 선택 → "요구사항으로 만들기", 원문 위치로 이동
- [x] 화면 ↔ 요구사항 연결, 반영 상태·메모
- [x] ★ 화면 인스펙터: 기획 탭(요구사항·문서) / 개발 탭(사용 컴포넌트·토큰·치수)
- [x] 문서 분할 보기: 요구사항 클릭 → 연결 화면 하이라이트, 화면 클릭 → 문서 해당 위치로 스크롤
- [x] 디자인 시스템: 컴포넌트·토큰 등록(수동 + CSV/JSON 붙여넣기), 사용 화면 역추적
- [x] 요구사항 보드: 프로젝트 전체 목록, 상태 필터, 미반영 모아보기

## Phase 2: 캔버스를 피그마답게 (2~4주차, ~2026-12-20)

### 전제 조건
- Phase 1이 배포되어 팀이 실제 프로젝트로 쓰고 있는 상태

### 목표
디자이너가 간단한 화면은 피그마 대신 여기서 바로 만들고, 기획 검수는 AI 도움으로 더 빨라진다.

### 기능
- [ ] 오토레이아웃(Stack): 방향·간격·패딩·정렬·크기(Fixed/Hug/Fill), 줄바꿈
- [ ] 정렬·분배 도구, 스냅·스마트 가이드, 간격 측정(Alt 호버)
- [ ] 컴포넌트 인스턴스: 바드림 컴포넌트를 캔버스에 끌어다 놓기, `props_schema`로 속성 패널 자동 생성 (Deus 방식)
- [ ] 섹션 → "내 모듈" 저장·재사용 (디테일페이지스튜디오 패턴)
- [ ] 코멘트: 화면 위치·요구사항에 핀, 멘션, 해결 처리
- [ ] 버전 스냅샷: 화면·페이지 단위로 저장·이름·고정·복구
- [ ] AI 요구사항 초안: 문서 → 요구사항 목록과 해당 화면 후보 제안 → 사람이 확정 (`origin: ai`)
- [ ] 노션 연동(Notion API), 한글(HWP) 업로드 검토, 다크 모드
- [ ] 이미지·PNG 내보내기 (화면 단위, 1x/2x)

### 추가 데이터
Comment, ScreenSnapshot, Module, Component.props_schema 사용 시작, 레이어 타입 `instance` + `layout` 속성

### 통합 테스트
- Phase 1 시나리오 A~D가 여전히 정상 동작하는지 확인
- 기존 화면 JSON(`schemaVersion: 1`)이 새 버전에서도 열리는지 확인 (마이그레이션 함수 필수)

## Phase 3: 피그마 대체 (2개월~)

### 전제 조건
- Phase 1 + 2가 안정적으로 운영 중이고, 신규 화면 작업의 일부가 이미 이 툴에서 이뤄지는 상태

### 목표
같은 화면을 여러 명이 동시에 편집하고, 프로토타입과 코드 핸드오프까지 이 툴에서 끝낸다.

### 기능
- [ ] 실시간 동시편집 + 접속자 아바타·커서 (화면 JSON → Yjs/Loro 문서로 전환)
- [ ] 프로토타입: 탭/호버 → 화면 이동, 전환(즉시/푸시/스프링), ▶ 미리보기
- [ ] 코드 탭: 선택 화면 → Vue 코드(바드림 디자인 시스템 컴포넌트 기준), 접근성 안내 주석
- [ ] 피그마 파일 가져오기: 피그마 레이어 → 편집 가능한 노드 변환 (주요 타입부터)
- [ ] 펜·벡터·불리언·마스크
- [ ] 프로젝트 반영률 대시보드, 팀 플러그인(확장 기능) 구조
- [ ] 성능: 화면 수백 장 페이지에서 화면 밖 요소 렌더링 생략, 캔버스·도구 영역 분리 (Deus의 iframe 분리 참고)

### 주의사항
- 실시간 동기화 서버 비용·운영이 생긴다 (Supabase Realtime 한도 또는 별도 서버).
- 피그마 API 호출 한도 때문에 대량 가져오기는 나눠서 실행해야 한다.
- 이 단계부터는 개발자 리뷰를 받는 것을 강하게 권장한다.
